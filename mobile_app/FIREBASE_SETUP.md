# Firebase Setup for Vangari Mobile

Run these commands locally from the repository root after installing Flutter and Firebase CLI.

```bash
cd mobile_app
flutter pub get
dart pub global activate flutterfire_cli
flutterfire configure
```

## What these commands do

- `flutter pub get` installs Flutter dependencies from `pubspec.yaml`.
- `dart pub global activate flutterfire_cli` installs the FlutterFire CLI.
- `flutterfire configure` connects this Flutter app to a Firebase project and generates real Firebase configuration files.

## Required Firebase services

Enable these in Firebase Console:

1. Authentication
   - Phone provider for customer OTP login
   - Email/password provider for admin login
   - Admin email for MVP: `munimm247@gmail.com`

2. Cloud Firestore
   - Use the rules in `../firebase/firestore.rules`

3. Firebase Storage
   - Use the rules in `../firebase/storage.rules`
   - Used for payment proof uploads

4. Firebase Analytics
   - Track signup, pickup request started, booking confirmed, collector assigned, picked, paid

5. Firebase Crashlytics
   - Track Android app crashes

## Files generated by FlutterFire

After running `flutterfire configure`, this file should be replaced:

```text
lib/firebase_options.dart
```

For Android, Firebase also generates or requires:

```text
android/app/google-services.json
```

Do not commit private service-account JSON files.

## After setup

Run:

```bash
flutter run
```

If Firebase initialization fails, check that `lib/firebase_options.dart` was generated correctly and that the selected Firebase project has Android app support enabled.
